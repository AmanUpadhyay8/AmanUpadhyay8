### What I'm building

**SpendLens**
Personal finance analytics from your inbox. Uses Gmail's read-only API to extract bank transactions through a hybrid rule-based + AI pipeline and turns them into spending insights.

**PrepPilot**
A NEET preparation platform built around a large question bank, mock tests, mistake tracking, and analytics. Built an extraction and classification pipeline using local LLMs to turn unstructured question data into structured datasets.

**FastJobs**
Job aggregation platform with automated scraping, fallback APIs, deduplication, TTL-based cleanup, and scheduled ingestion pipelines.
